# Whiskey's Bistro 🐾

A dog-friendly restaurant website built for an Introduction to Web Development course.

## About the Project

Whiskey's Bistro is a fictional pet-friendly bistro website. The site was designed and built from scratch using only HTML, CSS, and JavaScript — no frameworks or libraries.

## Features

- Responsive layout that works on desktop, tablet, and mobile
- Interactive menu with category filter buttons (Starters, Mains, Desserts, Drinks, Pup Menu)
- Image gallery slider with auto-advance, dot indicators, and touch swipe support
- Contact form with basic validation
- Hamburger menu for mobile navigation
- Smooth scroll and active nav link highlight on scroll
- Back to top button

## Built With

- HTML5
- CSS3 (Flexbox, CSS Grid, media queries)
- Vanilla JavaScript (no frameworks)
- Google Fonts — Playfair Display, Nunito, Dancing Script
